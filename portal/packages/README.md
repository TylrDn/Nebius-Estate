# Packages

| Package | Role |
|---|---|
| `app` | Backstage app (new frontend system): nav, themes, layout, sign-in |
| `backend` | Backstage backend: auth, permission policy (`permissionPolicy.ts`), the Nebius Estate backend plugin |
| `nebius-domain` | Shared typed contracts (`api.ts`) and pure logic (money, resources, repo model, billing, pricing, capacity, provisioning, permissions) |
