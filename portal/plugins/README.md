# Plugins

| Plugin | Role |
|---|---|
| `nebius-estate` | Frontend: every page, the design system (`src/ui/`) and the Costs and Commercial pages (`src/commercial/`) |
| `nebius-estate-backend` | Backend: inventory connectors (Nebius REST, Kubernetes, Prometheus), repository model, evidence, provisioning, FOCUS billing, rate books and scenarios (`src/commercial/`), configuration and access (`src/lib/`) |

See [docs/portal/architecture.md](../../docs/portal/architecture.md).
