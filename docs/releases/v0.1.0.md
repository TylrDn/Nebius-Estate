# Proposed v0.1.0 — experimental source

**Draft release notes. Publication is not approved; no release tag or GitHub release is created
by this document.** See the [publication checklist](../release-readiness.md#publication-approval-checklist).

Nebius Estate combines an experimental GPU infrastructure cookbook, guarded operator tooling,
dated evidence and a Backstage portal. Start with the credential-free synthetic demo and the
[five-step tour](../portfolio.md#five-step-demo-tour). Original development history remains private.

## Included

- Infrastructure recipes, Terraform modules and stacks, Kubernetes workloads, policies and runbooks.
- Portal source, synthetic test data, a collapsed walkthrough and explanations of reported billing
  versus hourly estimates.
- Node 24.22.0 pins and a regression for the native SQLite cleanup failure; isolated demo startup
  and shutdown, including a physical private SWC cache on macOS.
- Committed dependency source patches, regression tests, upstream references and retained licenses.

## Verification evidence

The [release record](../release-readiness.md) records local macOS/Linux checks: 1,332 unit/integration
tests on each platform, three existing skips, 40 installed-dependency security/compatibility checks,
17 script checks, builds and configuration checks. Linux Chromium passed 398 checks with retries
disabled. Infrastructure CI, Soperator mock plans, release regressions, source scans and link checks
passed within the documented platform/network limits. Fresh-clone onboarding results are recorded
separately there and in the private verification manifest.

These are source verification results. Historical cloud measurements retain their original dates
and methods; preparing this release runs no new paid GPU workload or cloud deployment.

## Known limitations

The complete dependency audit still reports **two High and one Low** upstream advisory. Local
patches mitigate reproduced cases; official fixed versions and owner risk acceptance remain
unrecorded. Read the [advisory decision record](../security/advisory-release-decision.md) and
[patch details](../security/dependency-backports.md) before evaluating the portal.

The portal's shared-deployment authentication integration is incomplete. This experimental source
has no production support commitment. The proposed release includes source with its notices and
provenance; built images, installed dependencies, browser bundles, documentation mirrors and raw
private evidence are outside this distribution review.

## Reporting and maintenance

Follow [SECURITY](../../SECURITY.md) for private reports. At publication, enable and test the reporting
channel before relying on its link. Local patch bypasses and regressions are in scope. The proposed
maintenance owner and review deadline require owner confirmation in the advisory decision record.

Actions remains disabled during private preparation. Publication or later CI enablement requires
the owner's explicit approval; this draft requests no paid GitHub Actions minutes.
