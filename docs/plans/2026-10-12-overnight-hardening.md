# Overnight hardening — 2026-10-12

> **Scope:** every change must close a finding below and meet its acceptance check.
> Nothing else goes in. Offline only: no `nebius`, `terraform apply/plan` against the cloud,
> `kubectl` against a cluster, or GitHub settings changes. Never load `.env` into a test.

**Goal:** every estate component reaches "re-runnable cleanly every time" offline, with harnesses that
turn "optimized" into a measured pass/fail, so one batched live pass (approved by the owner in the
morning) can prove it.

**Branching:** integration branch `overnight/2026-10-12`. Each workstream commits on
`overnight/ws-<id>` (from the integration branch) in its own worktree. Nothing reaches `main` until the
owner reviews in the morning.

## Global constraints

- Gates on every workstream before it is offered for merge (all must pass, outputs read):
  - toolbox: `make ci-docker TARGETS="ci soperator-check scan links"`
  - portal (if `portal/` touched): `yarn tsc`, `yarn lint:all`, `CI=1 yarn test`, `yarn test:e2e`, `yarn config:check` (Node 24 at `~/.local/node-v24/bin`)
  - gitleaks on the branch diff: `git diff overnight/2026-10-12... | docker run --rm -i --platform linux/amd64 -v "$PWD:/repo" -w /repo nip-toolbox gitleaks stdin --config .gitleaks.toml --no-banner`
  - no real resource ids (patterns `-e00` followed by 10+ chars other than mock/sentinel ids) in the diff
- A red gate is fixed or the change is reverted; never weakened, skipped or retried until green.
- New behaviour gets a test that fails without it (TDD), in the repo's existing test style
  (`tests/scripts/test-*.sh`, Terraform `*.tftest.hcl`, Jest, Playwright).
- Follow `docs/naming.md`, the comment density and idiom of the surrounding code, and existing docs tone.
- Do not invent Nebius facts (prices, quotas, GPU availability, APIs). Unknowns are written as unknowns.
- Upgrades: patch/minor bumps only, each only if every gate stays green; majors are listed, not applied.
- Blocked step (permission denial, needs cloud, needs a GitHub setting): skip it, record it in
  "Blocked" below with the exact command for the owner, continue.
