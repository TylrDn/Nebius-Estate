Result: **job 3 COMPLETED, ExitCode 0:0, on cpu-0**. `nvidia-smi: command not found` is expected on the CPU worker (hello.sh's GPU step fails on a CPU node; the job still finishes).

Why the apply did not finish: the recipe's `wait_for_soperator_activechecks_hr` waits for `ensure-healthy-nodes`, a slurmJob check whose status the checks controller reads through the Slurm REST API (`soperator-rest-svc`). Soperator creates the REST API only when accounting is enabled (`nebius/soperator internal/controller/clustercontroller/rest.go:39`); this lab runs with `accounting_enabled = false`, so the check ran (Slurm job 2) but can never report done. Controller log: `failed to get slurm job status ... lookup soperator-rest-svc.soperator ... no such host`.
