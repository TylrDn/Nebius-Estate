## What this does and does not show

- Shows: the managed driver image path (ADR-0003) boots, hands a Blackwell GPU to a pod, and
  NCCL initialises on it; a preemptible 1-GPU node group with no spot pricing setting was
  accepted by the API (this repo now sets `follows_spot_price`, [R1-2](../upstream-findings.md#r1-inference-and-managed-kubernetes)).
- Does not show: InfiniBand, multi-GPU collectives, this repo's roots, or any serving number.
- Lessons folded in: `k8s_version` must be pinned (`v1.36.3` arrived as the backend default and is
  outside Soperator's window); `1gpu-24vcpu-346gb` is the B300 single-GPU preset
  (`platform/regions.yaml`).
